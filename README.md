The funniest cat voicemail greeting in 120 characters: Miso the cat has taken over the laptop you needed, and your message will be ignored at 4 a.m.

The entry line:

> You've reached Miso. I'm sitting on the laptop you needed. Leave a message, and I'll ignore it at 4 a.m.

## Run it

```sh
python3 main.py
```

Writes the greeting to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then re-reads it to verify the bytes. Pure standard library, deterministic: the same line on every run.
